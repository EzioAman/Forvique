All components are created in the `components/` folder & must inherit global themes.
All components that are new must be made first in `app/'component_cehc` folder & then move it to components only after user is happy with how the component feels. If its ui component and can be imported again, put in the `components/ui` folder.
The components_check is the first place to check the components after creation, after every new ui component code, show it to user through the route and ask for approval.

### Component system

Establish reusable components and their variants.
Avoid creating multiple components that perform the same visual or functional role.
